# Bunny Shooter — weapons update

## Controls
- WASD — movement
- Shift — run
- Space — jump
- Left mouse — shoot
- 1..5 — inventory slots
- R — reload (or restart after death/victory)
- Esc — release mouse

## Weapons
- Pistol — 12 rounds, 1.5s reload
- Rifle — 30 rounds, 2.0s reload
- Shotgun — 8 rounds, no reload cooldown (it refills automatically)
- Sniper — 1 round, 5.0s reload
- Blaster — 8 rounds, 2.8s reload

Weapons are pickups placed around the map. Walking into one adds it to the first free inventory slot, up to 5 slots. Each weapon has its own HUD crosshair.

The houses use four solid wall colliders so the player can touch the exterior but cannot walk through into the building.
